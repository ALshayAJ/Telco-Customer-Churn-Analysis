# Telco Customer Churn Analysis

## Project Overview

This project analyzes customer churn in a telecommunications company to identify patterns and factors associated with customer attrition.

The analysis uses MySQL for data cleaning and exploratory data analysis, and Microsoft Excel for dashboard development and data visualization.

## Dataset

- **Source:** IBM Telco Customer Churn Dataset
- **Total Customers:** 7,043
- **Original Columns:** 33

The dataset contains customer demographics, subscribed services, contract details, billing information, and churn status.

## Tools Used

- MySQL 8.0
- Microsoft Excel

## Project Objectives

- Analyze the overall customer churn rate.
- Identify customer segments with high churn rates.
- Explore the relationship between contract types and churn.
- Analyze customer tenure and monthly charges.
- Investigate the impact of subscribed services on customer retention.
- Identify the most common customer churn reasons.

## Project Workflow

1. Data preparation and cleaning using MySQL.
2. Exploratory Data Analysis (EDA) using SQL.
3. Identification of key findings and business insights.
4. Dashboard development and visualization using Excel.

## Key Findings

- The overall customer churn rate was **26.54%**.
- Month-to-month contracts had the highest churn rate at **42.71%**.
- New customers (0–12 months) had the highest churn rate at **47.44%**.
- Fiber optic customers had a churn rate of **41.89%**.
- Customers without Online Security had a churn rate of **41.77%**.
- Churned customers had higher average monthly charges (**$74.44**) than retained customers (**$61.27**).

## Business Recommendations

- Improve retention strategies for new customers.
- Encourage long-term contracts through competitive offers.
- Investigate the high churn rate among Fiber Optic customers.
- Improve customer support and service quality.
- Review additional service offerings and pricing.

## Conclusion

This project highlights customer churn patterns and identifies customer segments that may require targeted retention strategies. The findings provide insights that can support better customer retention decisions.
